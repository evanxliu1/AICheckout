# Verification conventions

How verifiers and adjudicators label expansion cards. [`general.md`](general.md) holds the rules for every issuer; each issuer has its own file for decisions specific to its cards. When a new issuer decision is made, add it to that issuer's file (with the date) rather than to the general rules, unless it applies across issuers.
