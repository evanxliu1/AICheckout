# Security policy

Please report security vulnerabilities privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability** (<https://github.com/evanxliu1/AICheckout/security/advisories/new>). Do not open a public issue for a vulnerability.

Include the affected component (extension, API, review app or public site), the version or commit, steps to reproduce and the impact you expect. Do not include real card numbers, credentials, passphrases, complete cart pages or other personal data; use made-up values.

Reports are handled on a best-effort basis by the AI Checkout project; there is no bug bounty and no guaranteed response time. Supported code is the latest `main` branch and the latest published extension release.
