# Security policy

## Supported versions

Security fixes go to the latest `main` branch and the latest published release of the extension.

## Report a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting: on the repository's **Security** tab, choose **Report a vulnerability**, or go to <https://github.com/evanxliu1/AICheckout/security/advisories/new>. Don't open a public issue for a vulnerability.

In your report, include:

- The affected component: the extension, the API, the review app or the public site.
- The version or commit.
- Steps to reproduce the issue.
- The impact you expect.

Don't include real card numbers, credentials, passphrases, complete cart pages or other personal data. Use made-up values instead.

## What to expect

The AI Checkout project handles reports on a best-effort basis. There's no bug bounty and no guaranteed response time.
